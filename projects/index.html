Projects

Studybook.AI

A RAG study assistant built with LangChain, Hugging Face embeddings and FAISS, with multi-model orchestration (OpenAI, Gemini, Perplexity) and automatic fallback.

Cyclomatic Complexity Analyzer

A static analysis tool in C++ that walks Clang’s AST to compute cyclomatic complexity for C#/C++ source files, built with CMake and LLVM.

Tile Anomaly Detection

A fine-tuned YOLO model in PyTorch that detects defects in tiles with 86% accuracy, deployed on edge devices with TensorRT and DeepStream.

News Headline Sentiment

Scraped 50K+ headlines with Selenium and fine-tuned BERT on them, reaching 89% accuracy; served through a Flask API and a React visualization.

Firmographic Intelligence Pipeline

An LLM and NLP data pipeline that processes 1,000+ market data entries and news feeds daily. Published in IJSREM.

Personal Portfolio
